## Findings that materially change the proof

**Version drift is already visible.** Paseo web navigation labels v0.7 current/v0.8 beta, while release metadata returns v0.8.0. Released SDK event docs use caller-specified subscription IDs; today's main-branch docs describe server-issued IDs and stronger reconnect snapshots. Pin matched client/daemon versions. Do not copy main-branch reconnect claims into a v0.8.0 acceptance report. [Release docs](https://github.com/getpaseo/paseo/blob/v0.8.0/public-docs/sdk/events.md), [current docs](https://paseo.sh/docs/sdk/events).

**A permission UI is only one link.** For Maestro, inspected source parses Claude choices from pane text and another path records wake confirmation. This is useful implementation evidence, not proof that two independent requests are identified correctly and approved work resumes. For hcom, documented auto-approval of its own commands is narrower than general delegated tool permissions.

**Human-owned isolation is not solved by hiding tools.** Paseo's daemon permissions are broad, and its MCP docs distinguish catalog restrictions from a shell-access security boundary. Trial sessions must be isolated from protected work; a software ownership check must not be described as a security boundary against arbitrary shell access. [Paseo MCP](https://paseo.sh/docs/mcp).

**Native routes deserve a fair trial.** Claude's local notice is a real low-cost runtime subscription, but not a remote approval handler. Codex App Server's remote transport remains documented as experimental/unsupported for production; a thin integration must account for that rather than silently promoting it to a production backbone.

**OpenClaw's current docs favor native Codex control when enabled**, with ACP a separate explicit route. The installed repair's use of interactive Claude/tmux is historical implementation, not proof ACP is unsuitable. Parent-owned ACP completion and general peer A2A delivery have different semantics; adding both can create echo loops. [ACP routing](https://docs.openclaw.ai/tools/acp-agents), [delivery](https://docs.openclaw.ai/tools/acp-agents/delivery).

**No candidate is certified as the complete organization.** Source inspection supports selecting the cheapest decisive experiment. It does not close the live trial, independent-session survival, two-prompt, cross-Mac, phone or decision-to-deployment obligations.
