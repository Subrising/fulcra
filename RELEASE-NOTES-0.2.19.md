# Fulcra 0.2.19

Native `create_agent` sends a finish notice.
`fulcra usage events` shows event counters. The deterministic dispatcher uses `daemon.eventDispatcherEnabled`.
MCP tools can return compact output with `fullResult`.
`fulcra check identity|branch|worktree|session` checks work state.
The idle-lead nudge uses `fulcra.hold` labels and `daemon.idleLeadNudge` settings.
`daemon.idleLeadNudgeSkipOwners` excludes selected owners. Notices send only when eligible work grows.
The progress board has its own screen. Board text hides private data.
Archive safety counts unread native reports.
The compatibility core version remains 0.11.2.
