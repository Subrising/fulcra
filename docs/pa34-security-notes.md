# PA34 dependency reachability and release notes

Scope: INT Round 17 npm production audit, final product f5a97bcb2 and packaged FD-1 candidate 809f7d78. `omit=dev` still includes compiler/emulator dependencies carried by Expo and website workspaces. It is not a shipped-reachability analysis.

Nano ID is class (a): Expo Router, React Navigation and Gorhom Portal bundle `nanoid/non-secure` into the renderer. Update it within major 3; keep all npm overrides unchanged. Its normal navigation calls use the default size, but that is not grounds to retain an affected shipped version.

The following are class (c) release-note exceptions, not claims that these versions are fixed. They remain audit debt for build/CI environments. No audited high package is a class (b) server dependency. This conclusion uses dependency-parent tracing, packaged ASAR/unpacked manifests and source imports; bundled renderer dependencies must be considered separately from standalone manifests.
